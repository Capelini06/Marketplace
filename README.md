# Voltra Tech - Loja de Eletrônicos

Marketplace em PHP + MySQL de produtos eletrônicos (smartphones, notebooks, áudio e acessórios).

## Como rodar

1. Importe o arquivo `schema.sql` no MySQL (cria o banco `voltra_tech` com dados de exemplo).
2. Ajuste as credenciais em `config/conexao.php`, se necessário.
3. Sirva a pasta do projeto pela raiz (ex.: `php -S localhost:8000`).
